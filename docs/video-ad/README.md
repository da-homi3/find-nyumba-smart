# NYUMBASEARCH — “FIND. CONNECT. MOVE IN.”
## Premium AI Video Advertisement | Production Bible

**Runtime target:** 90–120 seconds (preferred cut: **~110s**)  
**Format:** 9:16 (TikTok / Reels / Shorts) + 16:9 (YouTube / LinkedIn / website)  
**Date:** August 2026  
**Brand line:** Find. Connect. Move in.

---

## 1. Creative direction (locked)

| Pillar | Direction |
|--------|-----------|
| Feeling | Human, calm, trustworthy, modern, Kenyan, premium, emotionally relatable |
| Visual | Cinematic realism + authentic smartphone/app footage. Real Nairobi residents, natural expressions, genuine apartments, subtle imperfections |
| Color | Warm cream `#F7F1E8`, deep cocoa `#4A2713`, soft gold/tan `#D4A84B`, natural greens `#0a8f3d` / `#086b2e` |
| Camera | Slow cinematic moves, handheld phone moments, gentle push-ins, tracking, map transitions, clean UI closeups |
| Music | Soft contemporary African-inspired instrumental — calm keys, subtle percussion, warm ambience; gentle build into uplift at CTA |
| Voice | Calm, warm, confident Kenyan/African English — conversational helper, not hard sell |
| Pace | ~125–145 WPM |

**UI fidelity:** Use real NyumbaSearch screenshots in `assets/` for logo, property cards, map, discovery, verify, landlord/manager portals, services, finance. Do **not** invent a different app UI.

| Channel | Status (as of Aug 2026 research) | Ad recommendation |
